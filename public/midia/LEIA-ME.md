## Como substituir
1. Abra a pasta `public/midia` no GitHub.
2. Clique em **Add file → Upload files** e envie os arquivos usando os nomes exatos acima.
3. Faça o commit. Como o projeto está conectado ao Lovable, as mudanças no branch `main` devem sincronizar com o editor.

Use imagens autorizadas pela cliente. Para fotos de antes e depois, mantenha o contexto real e a autorização de uso; evite retoques que alterem a percepção do resultado. Não inclua dados pessoais de pacientes.
